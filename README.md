# Nova

> Next-Generation Creative Intelligence & Design System Showcase

Nova is a high-performance web experience built with modern web technologies, zero external runtime dependencies, dynamic glassmorphic aesthetics, and responsive micro-interactions.

## Features

- **Dynamic Theme Palette**: Instant live theme switching across HSL color tokens (Electric Violet, Cyan, Emerald, Amber).
- **Interactive Laboratory**: Live 3D parameter tuning for scale, spatial rotation, and border curvature.
- **Bento Grid Architecture**: Showcasing capabilities with mouse-tracking radial glow effects.
- **Real-Time Visualizations**: Simulated telemetry dashboard chart and animated numerical performance counters.
- **Zero Dependencies**: Pure HTML5, CSS3, and modern Vanilla JavaScript with 100/100 performance profile.

## Quick Start

Run locally with any static file server, for example using Python:

```bash
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000) in your browser.
